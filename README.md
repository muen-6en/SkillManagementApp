# スキル管理

スキルの現在のレベル、目標、実践、ふりかえりをサイクル単位で記録するローカルWebアプリです。

## 主な機能

- 使い方ページ
- スキルの登録・編集・削除
- スキルへのタグ追加・削除
- スキル選定アシスタント
- 学習サイクルの記録
  - 現状
  - 目標のレベル
  - 実践
  - ふりかえり
- サイクルごとの差分確認
- サイクルごとの実績確認
- 学習の5段階の共通ナビゲーション

## 動作環境

- OS: Windows 10 / 11
- .NET SDK: 10.0 以降
- ブラウザ: Microsoft Edge、Google Chrome などのモダンブラウザ
- 推奨環境: PCブラウザ
- データベース: SQLite（ローカルファイル）
- 通信: ローカルHTTP（既定: `http://localhost:5079`）
- 認証: なし
- インターネット接続: 起動・通常利用には不要

## 起動方法

### 起動

PowerShellでプロジェクトディレクトリへ移動し、次を実行します。

```powershell
dotnet run --urls http://localhost:5079
```

ブラウザで次を開きます。

`http://localhost:5079/`

## 画面とURL

| 画面 | URL | 内容 |
| --- | --- | --- |
| 使い方 | `/` | アプリの使い方、サイクル、学習の5段階を確認 |
| スキル棚卸 | `/skills` | スキル・タグの登録と管理 |
| スキル選定 | `/skills/suggest` | 仕事のタスクから身に着けるスキル候補を整理 |
| 現状 | `/skills/{skillId}/cycles/{cycleId}/current` | 現在のレベルを登録 |
| 目標のレベル | `/skills/{skillId}/cycles/{cycleId}/target` | 目標のレベルを登録 |
| 実践 | `/skills/{skillId}/cycles/{cycleId}/practice` | やることと実践記録を登録 |
| ふりかえり | `/skills/{skillId}/cycles/{cycleId}/reflection` | ふりかえりと次サイクルを登録 |
| 差分 | `/skills/{skillId}/cycles/{cycleId}/diff` | 前回と今回の設定を比較 |
| 実績 | `/skills/{skillId}/results` | サイクル別の状態と記録件数を確認 |

## 基本的な使い方

1. `/` の使い方ページを確認する。
2. 「スキル棚卸」へ移動する。
3. スキル名を入力して追加する。
4. 必要に応じてタグを追加する。
5. 「編集」から現状を登録する。
6. 「目標のレベルへ進む」またはパンくずから目標のレベルを登録する。
7. 実践画面で「やること」を保存する。
8. 実際に行った内容を実践記録として追加する。
9. ふりかえりを保存し、必要なら次のサイクルを作成する。
10. 「差分を見る」や「実績確認」で過去の状態を確認する。

## スキル選定アシスタント

`/skills/suggest` では、スキル棚卸に登録するスキル候補を整理できます。

### 仕事で困っていることから考える場合

1. 棚卸対象期間の名前を入力する。
2. 棚卸対象期間を選ぶ。
   - 開始日のみ: 1日
   - 開始日と終了日: 連続した期間
3. その期間のタスクを複数登録する。
4. タスクごとに「課題を確認」を押す。
5. 時間、難しさ、他者への依存、手戻り、改善余地を回答する。
6. すべてのタスクを確認して「課題を確定」する。
7. 課題とスキル候補の表から候補を選ぶ。
8. 選択した候補をスキル棚卸へ追加する。

タスクと回答はSQLiteに保存され、スキル選定画面を離れても残ります。タスクの削除操作を行うまで保持されます。

「将来やりたい仕事から考える」「今の自分の状況から考える」は、現行の質問と候補表示を使用します。

## 学習の5段階

現状と目標のレベルでは、次の5段階から選択します。

1. 無意識的無能: 知らないし、できない
2. 意識的無能: 知っていても、できない
3. 意識的有能: 考えると、できる
4. 無意識的有能: 考えなくても、できる
5. 無意識的有能に意識的有能: どこからでも、教えられる

画面右下の「学習の5段階」ボタンから、全ページで説明を表示・非表示できます。

## データ保存

- データベース: SQLite
- 保存先: `%LocalAppData%\SkillManagementApp\skillmanagement.db`
- データはアプリを再起動しても保持される。
- データベースファイルはプロジェクト外に保存される。
- データを削除するまで自動削除されない。

## 技術構成

- Blazor Web App
- Interactive Server
- ASP.NET Core
- Entity Framework Core
- SQLite
- C# のみ

認証、外部API、生成AI、自動レベル判定は使用しません。

## GitHubへ公開する場合の注意

- `bin/`、`obj/`、SQLiteファイルは公開しない。
- `%LocalAppData%` 配下のデータベースをリポジトリへコピーしない。
- 接続文字列、APIキー、個人情報を設定ファイルへ追加しない。
- このアプリは認証なしのローカル利用を前提とする。公開サーバーへそのまま配置しない。
